          Sistema — Backup & Manutenção

          Backup dos Dados

          O sistema armazena os dados no localStorage do seu navegador. Faça backups regularmente para não perder dados se limpar o navegador.

          Backups Automáticos

          O sistema salva automaticamente uma cópia dos seus dados a cada 3 dias. Os últimos 3 backups automáticos são mantidos.
